# Наряд №033 — Слой провайдеров и BYOK: интерфейсы, fake-провайдеры, кэш вызовов, учёт стоимости

**Волна:** 0 (Фундамент)  
**Стадия:** infra  
**Размер:** L  
**Исполнитель:** agent  
**Зависит от:** #35, #36  
**Связанные ADR:** ADR-0004  
**Статус:** open

## Контекст
Все ML-функции работают через внешние API (ADR-0004). Слой провайдеров делает провайдера сменным, кэширует платные вызовы и считает стоимость. Реальные адаптеры делаются позже (№37–39) после выбора провайдеров (№4); здесь слой без сети, на fake-провайдерах.

## Контракт
```
razkadr.toml:
  [asr]        provider = "<имя>"  model = "<модель>"  api_key_env = "ASR_API_KEY"
  [embeddings] provider = "<имя>"  ...
  [vlm] / [llm] аналогично
  [keys] mode = "platform" | "user"       # платформенные ключи или BYOK
→
transcribe(audio_path) -> Transcript
embed_images(paths) / embed_texts(texts) -> list[Vector]
describe_image(path, prompt) -> str
complete(messages) -> str
→ каждый вызов дописывает в run.json: стадия, провайдер, модель, секунды/токены/изображения, стоимость, cache_hit
→ смена `provider` в конфиге не требует правки кода стадий
```

## Scope
- Интерфейсы (Protocol) для ASR, эмбеддингов (текст и изображения), VLM, LLM и единые типы результатов.
- Fake-провайдеры (детерминированные, без сети) для всех четырёх задач; именно на них пишутся тесты стадий.
- Загрузка ключей из переменных окружения или из конфигурации пользователя; режим `mode = user` (BYOK).
- Кэш вызовов по хэшу входа и параметров (повторный платный вызов не выполняется).
- Учёт стоимости по тарифам из конфигурации (тариф и дата тарифа задаются вручную).
- Повторы с ожиданием при временных ошибках; понятные ошибки при неверном ключе или исчерпанной квоте; лимит параллелизма и частоты в конфигурации провайдера.
- Маскирование ключей во всех логах, исключениях и `run.json`.

## Non-goals
- Реальные адаптеры провайдеров (№37–39).
- Хранение ключей пользователей в БД и шифрование (веб-волны).
- Биллинг пользователей.

## Acceptance criteria
- [ ] Пример из контракта проходит на fake-провайдерах без сети
- [ ] Смена провайдера правкой конфигурации подтверждена тестом
- [ ] Повторный вызов с теми же входами не обращается к провайдеру (тест на счётчик вызовов), в `run.json` `cache_hit=true`
- [ ] Ключ отсутствует в логах, `run.json`, тексте исключений (тест, ищущий ключ по всем артефактам)
- [ ] Расчёт стоимости проверен табличным тестом
- [ ] Документация конфигурации добавлена
- [ ] CI зелёный

## Assumptions / Open questions
- Валюта учёта: USD; тарифы вносятся владельцем после наряда №4.
- Кэш вызовов хранится на диске в каталоге кэша (`~/.cache/razkadr/` или из конфигурации).

## Проверка аудитора
- Попробовать «сломать» маскирование: передать ключ необычной формы и проверить все файлы.
- Проверить, что интерфейсы не привязаны к особенностям одного провайдера (например, к формату ответа).
- Проверить, что кэш учитывает версию модели и параметры, а не только вход.
