# Storyboard v1.0 — схема и правила

Storyboard — центральный объект Razkadr (см. `docs/spec.md` §3.1): типизированный JSON, в котором человек может поправить любой кадр и текст до сборки документа. Все стадии конвейера читают и пишут этот формат; реализацию стадии можно заменить, не трогая остальные.

- Машиночитаемая схема: [`schemas/storyboard.v1.json`](../schemas/storyboard.v1.json) (JSON Schema, draft 2020-12).
- Валидация: `razkadr validate <файл>` — печатает `ok` и возвращает код 0, либо список проблем в stderr (по одной на строку) и код 1.
- Примеры: `examples/storyboard.valid.json`, `examples/storyboard.valid-edited.json`, `examples/storyboard.invalid.json`.

## Общий вид

```json
{
  "schema_version": "1.0",
  "project":  { "id", "title", "preset", "output_lang" },
  "sources":  [ { "id", "path", "url?", "duration_s?", "detected_lang?" } ],
  "episodes": [ { "id", "role", "source_id", "t_start", "t_end", "frame",
                  "alternatives?", "text?", "user_edited?" } ]
}
```

Неизвестные поля запрещены на всех уровнях (`additionalProperties: false`), кроме `score_parts`, где ключи задаются пресетом скоринга. Расширение схемы — осознанное действие: minor-версия схемы и обновление кода в одном изменении (см. «Версионирование»).

## Поля верхнего уровня

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| `schema_version` | string | да | Версия схемы, semver (`1.0`, `1.0.0`, `1.1`); patch-часть может опускаться. |
| `project` | object | да | Паспорт документа. |
| `sources` | array | да | Источники видео. Может быть пустым только при пустом `episodes`. |
| `episodes` | array | да | Эпизоды документа. Пустой массив допустим (черновик без отбора). |

### project

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| `id` | string | да | Стабильный идентификатор проекта. |
| `title` | string | да | Заголовок документа, попадает на титульный слайд. |
| `preset` | string | да | Сценарный пресет: определяет набор ролей эпизодов и профиль скоринга. MVP: `recipe`. |
| `output_lang` | lang | да | Язык документа (BCP-47). MVP: `ru`, `en`. |

### sources[i]

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| `id` | string | да | Идентификатор, на который ссылаются `episodes[].source_id`. Уникален. |
| `path` | string | да | Локальный путь к нормализованному видео. |
| `url` | string | нет | Исходная ссылка, если видео загружено по URL (учёт происхождения). |
| `duration_s` | number ≥ 0 | нет | Длительность в секундах. Если задана — время эпизодов проверяется на выход за неё (допуск 1 мс на погрешности float). |
| `detected_lang` | lang | нет | Автоопределённый язык речи. |

### episodes[i]

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| `id` | string | да | Идентификатор эпизода, уникален в пределах Storyboard. |
| `role` | string | да | Роль в структуре документа из пресета (`hero`, `ingredients`, `step`, …). Схема не фиксирует набор ролей: его задаёт пресет (для `recipe` — наряд №13). |
| `source_id` | string | да | Ссылка на существующий элемент `sources`. |
| `t_start` | number ≥ 0 | да | Начало эпизода, секунды от начала источника. |
| `t_end` | number ≥ 0 | да | Конец эпизода; `t_end >= t_start` и не дальше `duration_s` источника. |
| `frame` | object | да | Кадр-представитель эпизода. |
| `alternatives` | array | нет | Запасные кадры, лучшие вперёд: `{ "path", "t", "score?" }`. |
| `text` | object | нет | Текст эпизода. Отсутствует в черновике до стадии «Текст» (волна 3 пишет его поверх валидного черновика). |
| `user_edited` | bool | нет | Флаг правки пользователя, по умолчанию `false`. |

### episodes[i].frame

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| `path` | string | да | Путь к файлу кадра. |
| `t` | number ≥ 0 | да | Таймкод кадра, секунды. |
| `score` | number 0…1 | нет | Итоговый скор кадра из стадии отбора. |
| `score_parts` | object | нет | Составляющие скора; ключи задаёт пресет (`sharpness`, `aesthetic`, `relevance`, …), значения нормированы в 0…1. |

## Текст эпизода (`text`)

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| `mode` | enum | да | `verbatim` \| `condensed` \| `described`. |
| `source_lang` | lang | нет | Язык исходной речи/подписей. |
| `original` | string | нет | Текст, полученный из источника (транскрипт, OCR). |
| `output` | string | нет | Текст на слайде (возможно, переведённый). |
| `output_lang` | lang | нет | Язык `output`. |

Режимы текста:

- **verbatim** — дословный транскрипт. Используется, когда точность формулировок и чисел критична; правки сводятся к пунктуации.
- **condensed** — сжатый пересказ своими словами с сохранением фактов, чисел и единиц (режим по умолчанию для шагов рецепта).
- **described** — описание кадра через VLM. Для немых видео без экранных подписей — единственный источник текста; помечается явно, чтобы приёмка могла проверить такие места выборочно.

Инвариант по числам (проверяется на шлюзе D инструментами наряда №20, не схемой): количества, время и температуры переносятся из `original` в `output` без изменений в любом режиме.

## Языки

Языковые поля (`project.output_lang`, `sources[].detected_lang`, `text.source_lang`, `text.output_lang`) — теги **BCP-47**. Схема допускает первичный тег и цепочку подпутей (например, `ru`, `en`, `pt-BR`); проверку по реестру IANA схема не выполняет. MVP поддерживает вывод `ru` и `en`; язык видео определяется автоматически и хранится в оригинале. Смешанная речь на границах эпизода — нормальный случай, `detected_lang` фиксирует доминирующий язык.

## Правила `user_edited`

Флаг ставит редактор при любом изменении эпизода пользователем: замена кадра (в том числе выбор из `alternatives`), правка текста, изменение порядка, удаление/добавление эпизодов.

Обязательное поведение стадий: при повторной генерации эпизод с `user_edited: true` переносится в новый Storyboard как есть; текст и кадр такого эпизода не перезаписываются. Стадии вправе обновлять только эпизоды с `user_edited: false`. Схема не отличает «правил только кадр» от «правил только текст» — это осознанное упрощение v1.0; при необходимости различений вводится в minor-версии.

## Версионирование

- `schema_version` — semver: `MAJOR.MINOR.PATCH`; patch может опускаться (`1.0` ≡ `1.0.0`).
- **MAJOR** — несовместимые изменения (удаление/переименование обязательных полей, смена типов). Новый файл `schemas/storyboard.vN.json`, мигратор и обновление всех стадий.
- **MINOR** — обратно совместимые добавления (новые необязательные поля, новые значения enum). Файл той же major-версии обновляется, валидатор принимает документы старой minor-версии.
- **PATCH** — правки описаний/документации без изменения валидности.

Валидатор принимает только major-версию, совпадающую с файлом схемы: `storyboard.v1.json` отвергает `schema_version: "2.0"` с сообщением `schema_version: unsupported major version '2', this schema validates v1.x`. Совместимость гарантируется в пределах major.

## Валидация и сообщения об ошибках

`razkadr validate <файл>` выполняет две группы проверок:

1. **Схема** (JSON Schema draft 2020-12): типы, обязательность, диапазоны, перечисления, запрет неизвестных полей.
2. **Семантика** сверх схемы:
   - уникальность `id` эпизодов и источников;
   - `episodes[].source_id` ссылается на существующий источник;
   - `t_end >= t_start`;
   - время эпизода не выходит за `duration_s` источника, если она задана (допуск 1 мс);
   - major-версия `schema_version` поддерживается.

Коды выхода: `0` — валидно (`ok` в stdout); `1` — невалидно; `2` — файл не прочитан или не является JSON.

Каждая проблема печатается отдельной строкой в stderr в формате `<json-путь>: <причина>`, в порядке «сначала схема, затем семантика». Примеры:

```text
episodes[0].frame.path: required
episodes[2].source_id: unknown source 'v9'
episodes[1].t_end: t_end (5.0) < t_start (12.4)
episodes[0].t_end: exceeds source duration_s (840.5)
episodes[3]: duplicate id 'e1'
project.output_lang: 'ru_RU!!' is not a valid regular expression match
```

JSON-путь построен как у jsonschema (`$.episodes[0].frame`) без ведущего `$`, индексы массивов — в квадратных скобках; путь указывает на точное место проблемы, включая отсутствующее обязательное поле (`episodes[0].frame.path: required` — путь отсутствующего поля `path` внутри `frame`).

## Известные упрощения v1.0

- `role` — свободная строка: набор ролей принадлежит пресету, а не схеме; контроль соответствия пресету выполняет стадия отбора (наряд №14).
- Путь кадра не проверяется на существование на диске: Storyboard валиден как документ, доступность файлов — ответственность стадий и `razkadr build`.
- `frame.t` не обязан лежать внутри `[t_start, t_end]`: кадр-представитель может выбираться из соседних мгновений; ограничение ужесточит minor-версия, если приёмка волны 2 покажет необходимость.
- Проверка тегов языка ограничена синтаксисом; реестр IANA не сверяется.
