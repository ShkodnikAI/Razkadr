# Наряд №040 — Сбор и разметка эталонного набора рецептов (8 видео)

**Волна:** 1 (Индексатор)  
**Стадия:** eval  
**Размер:** L  
**Исполнитель:** human  
**Зависит от:** #3, #41  
**Связанные ADR:** ADR-0005  
**Статус:** open

## Контекст
Качество отбора проверяется на размеченном наборе. Видео подбирает и размечает владелец проекта; задача выполняется параллельно с разработкой и блокирует только шлюз B. Агент не берёт этот наряд.

## Контракт
```
8 видео по ссылкам (YouTube, TikTok и др.) → data/eval/videos/*.mp4 (локально, не в git)
+ data/eval/labels/<id>.json + data/eval/SOURCES.md
→ `razkadr eval-check data/eval` без нарушений
```

Состав набора:
- 2 с русской озвучкой;
- 2 с английской озвучкой;
- 2 без речи, с экранными подписями;
- 1 без речи и без текста;
- 1 «плохого» качества (ручная съёмка, свет).
Длительность 3–15 минут.

## Scope
- Подбор ссылок, скачивание локально, запись в `SOURCES.md` (ссылка, дата, условия, локальный файл, теги).
- Разметка каждого видео: кадр готового блюда (hero), кадр ингредиентов, 5–8 ключевых шагов; помощь: HTML-галерея из №41.
- Вторая независимая разметка для 2 видео (оценка согласованности).

## Non-goals
- Распространение видео, публикация набора.

## Acceptance criteria
- [ ] `razkadr eval-check data/eval` проходит
- [ ] Состав набора соответствует перечисленному
- [ ] Согласованность двух разметок на 2 видео посчитана и записана в `data/eval/README.md`
- [ ] Видео не попали в git

## Assumptions / Open questions
- Видео скачиваются для внутренней оценки; условия платформ и права авторов проверяет владелец (не юридическая консультация).

## Проверка аудитора
- Проверить `SOURCES.md` на полноту.
- Выборочно проверить 10 % таймкодов разметки в галерее.
