# Шлюз D — приёмка волны 3 (Текст)

**Нарядов в волне:** #17, #18, #19, #20  
**Протокол:** `docs/acceptance/wave-3.md` (по `docs/acceptance/TEMPLATE.md`)  
**Решает:** аудитор готовит протокол, владелец принимает решение go / go с замечаниями / no-go.

## Критерии
- [ ] Ингредиенты ≥ 90 % верно (RU→RU, EN→RU, EN→EN) по чек-листу на 6 видео
- [ ] В выборке 50 текстов не более 2 несоответствий источнику
- [ ] Числа, время, температуры верны в 100 % проверенных случаев
- [ ] `described` для 2 немых видео приемлем для владельца
- [ ] Правки пользователя сохраняются (тест)
- [ ] Длина текста укладывается в лимит макета

## No-go
Ошибки в количествах выше порога; жёсткие меры (verbatim для чисел).

## Порядок
1. Все наряды волны закрыты, PR прошли аудит.
2. Аудитор запускает проверки сам (не со слов агента) и заполняет протокол числами из запусков.
3. Демонстрация владельцу, решение записывается в протокол.
4. При go: аудитор уточняет черновики нарядов следующей волны (снимает `draft`).
