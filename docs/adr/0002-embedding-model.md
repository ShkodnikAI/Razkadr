# ADR-0002 — Подход к эмбеддингам кадров и текста

**Статус:** proposed (окончательное решение по данным шлюза C)
**Дата:** 2026-10-15 (обновлён с учётом ADR-0004: только внешние модели)

## Контекст
Локальные модели не используются (ADR-0004). Поиск кадров по описанию можно строить двумя способами:
1. **Мультимодальные эмбеддинги через API:** кадры и запросы в общем пространстве.
2. **Описание кадров VLM + текстовые эмбеддинги:** кадр превращается в текст, поиск идёт по тексту.

Платные вызовы выполняются после дешёвой отбраковки кадров (pHash, резкость), поэтому число кадров на минуту видео — рычаг стоимости.

## Решение (предварительное)
Интерфейсы `Embedder`/`VectorStore` (наряды 010, 033) делают подход и провайдера сменными. На эталонном наборе (наряд 015) сравниваются минимум два варианта: мультимодальные эмбеддинги и VLM-описание + текст, а также гибрид. Выбор по hit@3 и стоимости минуты видео, с учётом условий провайдера (ADR-0004). Финальное решение фиксируется после шлюза C.

## Последствия
- Индекс хранит провайдера, модель и версию; смена требует переиндексации.
- Стоимость индексации входит в критерии шлюза B.
