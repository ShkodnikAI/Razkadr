# Наряд №026 — Экспорт HTML (таймкоды) и JSON

**Волна:** 4 (Раскладка и экспорт)  
**Стадия:** render  
**Размер:** M  
**Исполнитель:** agent  
**Зависит от:** #21  
**Связанные ADR:** —  
**Статус:** open

## Контекст
Интерактивная версия документа: по таймкоду можно перейти к моменту видео, JSON отдаёт Storyboard для других систем.

## Контракт
```
`razkadr export-html slides.json --out deck.html`
→ deck.html (самодостаточный, без CDN) + deck_assets/ с кадрами; каждый таймкод — ссылка на источник: для URL с параметром времени (YouTube `t=`), для локального файла — `file`-ссылка с `#t=`

`razkadr export-json storyboard.json --out storyboard.out.json`
→ валидный Storyboard (повторная проверка по схеме)
```

## Scope
- Одностраничный HTML с навигацией по слайдам (клавиши и клик), печатная вёрстка (@media print), тёмная и светлая тема.
- Правила построения ссылки на момент по типу источника (youtube.com, youtu.be, tiktok, локальный файл, прочее — без параметра времени, но с текстовым таймкодом).
- Экспорт JSON с валидацией.

## Non-goals
- Встроенный видеоплеер (видео не копируется).

## Acceptance criteria
- [ ] Пример из контракта проходит; страница открывается без сети и сервера
- [ ] Тест: число слайдов и таймкодов в HTML соответствует slides.json; ссылки на YouTube содержат верный `t=`
- [ ] Нет внешних запросов (проверка отсутствия http-ссылок на скрипты и стили)
- [ ] JSON проходит `razkadr validate`
- [ ] CI зелёный

## Assumptions / Open questions
- Для локальных файлов путь в ссылке абсолютный, переносимость не гарантируется.

## Проверка аудитора
- Открыть deck.html в браузере, пролистать, проверить клики по таймкодам.
