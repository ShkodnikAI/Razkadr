# Наряд №014 — Выбор эпизодов: пресет + индекс → Storyboard-черновик без текста

**Волна:** 2 (Отбор)  
**Стадия:** select  
**Размер:** L  
**Исполнитель:** agent  
**Зависит от:** #12, #13  
**Связанные ADR:** —  
**Статус:** open

## Контекст
Для каждой роли пресета выбирается лучший кадр и альтернативы с учётом порядка, разнообразия и качества. Результат — валидный Storyboard без текста.

## Контракт
```
`razkadr select runs/<id> --preset recipe [--out storyboard.json]`
→ storyboard.json, валидный по №2: эпизоды по ролям, у каждого frame, t_start/t_end, alternatives (≥2 где возможно), score_parts
```

## Scope
- Выбор по ролям с помощью №12; границы эпизода (t_start/t_end) по границам сцены/чанка.
- Разнообразие: штраф за близость к уже выбранным кадрам (pHash и время), чтобы шаги не повторялись.
- Порядок эпизодов по времени для шагов; соблюдение ограничений пресета.
- Запись `score_parts` и причины выбора в служебные поля (не ломая схему).
- Режим повторного выбора: эпизоды с `user_edited: true` не перезаписываются.

## Non-goals
- Генерация текста (волна 3).
- Раскладка по слайдам.

## Acceptance criteria
- [ ] На фикстуре с fake-провайдерами создаётся валидный Storyboard
- [ ] Альтернативы не совпадают с выбранным кадром и между собой (тест)
- [ ] Эпизоды с `user_edited` сохраняются при повторном запуске (тест)
- [ ] Разнообразие: два шага не выбирают почти одинаковые кадры (тест на дубль-фрагменте из №34)
- [ ] CI зелёный

## Assumptions / Open questions
- Число эпизодов определяется пресетом и длиной видео.
