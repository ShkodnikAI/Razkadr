# Наряд №003 — Эталонный набор рецептов и формат разметки

**Статус:** open (блокируется: нужны видео и разметчик)
**Волна:** 0
**Стадия конвейера:** оценка качества
**Версия схемы Storyboard:** 1.0
**Связанные ADR:** —
**Зависит от:** №001

## Контракт
```
data/eval/videos/*.mp4 (8 шт.) + data/eval/labels/<id>.json
→ `raskadr eval-check data/eval` печатает: 8 видео, 8 разметок, нарушений нет
```

Формат `labels/<id>.json`:
```json
{
  "video_id": "ru_voice_01",
  "tags": ["ru", "voice"],
  "hero": [{"t": 612.0}],
  "ingredients": [{"t": 14.5}],
  "steps": [{"t": 40.0, "note": "нарезка лука"}, {"t": 95.0, "note": "обжарка"}]
}
```
Допуск совпадения: ±2 с.

## Scope
- 8 видео: 2 RU-озвучка, 2 EN-озвучка, 2 без речи с экранными подписями, 1 без речи без текста, 1 плохого качества.
- Разметка: hero, ingredients, 5–8 steps на видео; допускается несколько допустимых кадров.
- `data/eval/SOURCES.md`: источник и права на использование каждого видео.
- Команда `raskadr eval-check` (проверка целостности: каждому видео есть разметка, таймкоды в пределах длительности, минимум шагов).
- Для 2 видео вторая независимая разметка (оценка согласованности).

## Non-goals
- Метрики поиска (наряд 015).
- Коммит самих видео в репозиторий (в `.gitignore`).
