# Наряд №015 — Eval-харнесс: метрики hit@k, отчёт, сравнение конфигураций

**Волна:** 2 (Отбор)  
**Стадия:** eval  
**Размер:** M  
**Исполнитель:** agent  
**Зависит от:** #3, #12  
**Связанные ADR:** ADR-0002  
**Статус:** open

## Контекст
Решения «лучше/хуже» принимаются по метрикам на размеченном наборе. Харнесс сравнивает конфигурации поиска и пишет отчёт, пригодный для протокола шлюза.

## Контракт
```
`razkadr eval data/eval --config A.toml --config B.toml [--k 1,3]`
→ таблица: конфигурация × роль → hit@1, hit@3 (допуск ±2 с), стоимость индексации минуты видео, число платных вызовов
→ eval/report.md и eval/report.json (воспроизводимо: версии, параметры, хэш разметки)
```

## Scope
- Метрики hit@k по ролям и видео, агрегаты, доверительная оценка (число видео в знаменателе указано).
- Режимы сравнения: текст-only / кадры-only / гибрид; разные провайдеры эмбеддингов.
- Работа на fake-провайдерах и фикстурах для тестов; на реальных данных после №40.
- Отчёт указывает, на каких видео и ролях промахи, со ссылками на кадры.

## Non-goals
- Подбор параметров (делается по отчёту на шлюзе C).

## Acceptance criteria
- [ ] Тест на игрушечной разметке и известном результате поиска даёт ожидаемые hit@1/@3
- [ ] Допуск по времени проверен граничными тестами (1.9 с / 2.1 с)
- [ ] Отчёт содержит стоимость и версии
- [ ] CI зелёный

## Assumptions / Open questions
- Hit засчитывается, если среди топ-k есть кадр в пределах допуска от эталонного таймкода роли.

## Проверка аудитора
- Пересчитать hit@3 для одного видео вручную и сравнить.
- Проверить, что знаменатель не включает видео без разметки соответствующей роли.
