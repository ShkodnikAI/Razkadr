# Наряд №004 — Выбор провайдеров API: условия, задержка, стоимость

**Волна:** 1 (Индексатор)  
**Стадия:** eval  
**Размер:** M  
**Исполнитель:** both  
**Зависит от:** #33  
**Связанные ADR:** ADR-0004  
**Статус:** open

## Контекст
Нужно решить, какие внешние API брать по умолчанию для речи, эмбеддингов, VLM и LLM, на основе проверенных условий и замеров, а не по памяти. Требуются API-ключи владельца (минимум два провайдера на задачу для сравнения).

## Контракт
```
API-ключи кандидатов + 1 минута тестового видео с речью + 20 тестовых кадров
→ docs/providers.md: таблица «задача → провайдер/модель → задержка → стоимость за единицу → стоимость за 1 минуту видео → замечания о качестве»
→ docs/adr/0006-default-providers.md (proposed): набор по умолчанию и запасной, условия провайдеров со ссылками на первоисточники и датой проверки
```

## Scope
- Скрипты замеров в `scripts/providers/` (задержка, стоимость, простая оценка качества).
- Проверка условий каждого провайдера: коммерческое использование результатов, хранение и обучение на данных, региональные ограничения, лимиты.
- Кандидаты: ASR (русский и английский, таймкоды, автоопределение языка), мультимодальные эмбеддинги либо VLM-описание + текстовые эмбеддинги, VLM для OCR и описаний, LLM для сжатия и перевода.

## Non-goals
- Реализация адаптеров (№37–39).
- Окончательный выбор подхода к эмбеддингам (ADR-0002, после волны 2).
- Юридическая консультация.

## Acceptance criteria
- [ ] `docs/providers.md` содержит замеры, полученные запуском (команды приведены)
- [ ] Условия провайдеров проверены по официальным страницам, дата проверки указана
- [ ] Для каждого провайдера статус: подходит / ограничен / требует уточнения
- [ ] ADR-0006 оформлен как proposed; принимает владелец
- [ ] Ключи не попали в репозиторий

## Assumptions / Open questions
- Владелец выдаёт ключи через переменные окружения вне репозитория.
- Бюджет на замеры невелик (минуты видео, десятки кадров).

## Проверка аудитора
- Выборочно проверить ссылки на условия провайдеров.
- Проверить, что цифры стоимости в таблице воспроизводятся скриптом.
- Убедиться, что в истории git нет ключей.
