# Наряд №021 — Движок раскладки: Storyboard → slides.json, макеты, автоподгон текста

**Волна:** 4 (Раскладка и экспорт)  
**Стадия:** layout  
**Размер:** L  
**Исполнитель:** agent  
**Зависит от:** #14  
**Связанные ADR:** ADR-0003  
**Статус:** open

## Контекст
Раскладка отделена от формата вывода (ADR-0003): движок превращает Storyboard в описание слайдов в виде слотов, а PPTX, HTML и PDF строятся из него. Работает и на Storyboard без текста (волна 2), и с текстом (волна 3).

## Контракт
```
`razkadr layout storyboard.json [--lang ru|en] [--out slides.json]`
→ slides.json (schemas/slides.v1.json): [{layout, slots, source_refs, warnings}]
```
Макеты и их слоты:
- `title`: заголовок, подзаголовок, кадр hero (фон);
- `hero_caption`: кадр hero, подпись (текст эпизода), таймкод;
- `ingredients_list`: кадр ингредиентов, список строк (до 12 на слайд; больше — перенос на следующий слайд);
- `steps_grid`: 2×2 или 3 колонки по числу шагов, у каждой ячейки кадр, номер, текст, таймкод; больше ячеек — следующий слайд;
- `serving`: кадр serving, подпись.

Слот кадра: `{path, t, episode_id}`. Таймкод — строка `мм:сс` (или `ч:мм:сс`) от `t_start` эпизода.

## Scope
- `schemas/slides.v1.json`, валидатор, подкоманда `razkadr layout`; запись в `docs/layout.md`: макеты, слоты, лимиты длины текста, правила переноса.
- Лимиты длины текста по слотам (в конфигурации); автоподгон: сначала перенос на новый слайд (список, сетка), затем сокращение по границе предложения/слова с многоточием; каждое сокращение пишется в `warnings` слайда, ничего не обрезается молча.
- Эпизоды без текста: слайд собирается (кадр + таймкод), в слоте текста пусто, без `warnings`.
- Подписи слайдов («Ингредиенты», «Шаг N») из таблицы RU/EN по `--lang`; язык текста эпизода не переводится (это волна 3).
- Выбор макета для роли: `hero → title + hero_caption`, `ingredients → ingredients_list`, `prep|steps → steps_grid`, `serving → serving`; отображение ролей в макеты задаётся в пресете или в конфигурации, не зашито в коде.
- Тесты на примерах `examples/storyboard.*.json` и на синтетических Storyboard (0, 1, 7, 30 эпизодов).

## Non-goals
- Рендер в какой-либо формат (№22, 24, 26).
- Перевод и генерация текста (волна 3).
- Пользовательские шаблоны (№23).

## Acceptance criteria
- [ ] Пример из контракта проходит на `examples/storyboard.valid.json`; `slides.json` валиден по схеме
- [ ] Storyboard без текста даёт валидные слайды без ошибок
- [ ] 7 шагов дают 2 слайда `steps_grid` по правилу переноса (тест); 30 эпизодов не падают
- [ ] Слишком длинный текст сокращается, а `warnings` содержит запись с id эпизода (тест)
- [ ] Результат детерминирован (два запуска дают идентичный файл)
- [ ] `docs/layout.md` описывает макеты и лимиты
- [ ] CI зелёный

## Assumptions / Open questions
- Соотношение сторон 16:9; другие форматы вне объёма.
- Лимиты длины подбираются по эталонному шаблону (№22) и могут быть уточнены его нарядом.
