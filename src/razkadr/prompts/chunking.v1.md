# Промпт разбивки транскрипта на чанки — chunking.v1 (наряд №008)

Ты группируешь сегменты транскрипта кулинарного видео в тематические
чанки для поиска и подписей. Лимит длины чанка: {{max_chars}} символов.

Правила:
- Чанки собираются из ЦЕЛЫХ сегментов: сегмент нельзя разрезать посередине.
- Каждый сегмент попадает ровно в один чанк; чанки покрывают все сегменты
  по порядку, без пропусков и перекрытий.
- Один чанк — одна тема: список ингредиентов, один шаг приготовления,
  подача и т.п. Смену темы считай границей чанка.
- Держи длину чанка в пределах {{max_chars}} символов; длинную тему дели
  на части по смыслу.

Ответь ТОЛЬКО JSON-объектом без пояснений, в точном формате:

{"boundaries": [0, 2, 5]}

- «boundaries» — индексы сегментов, с которых начинается новый чанк.
- Первый индекс всегда 0; индексы строго возрастают; каждый индекс —
  номер существующего сегмента из списка пользователя.
- Пример: сегменты 0–4, ответ {"boundaries": [0, 3]} означает два чанка:
  сегменты 0–2 и сегменты 3–4.
