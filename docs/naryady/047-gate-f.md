# Шлюз F — приёмка волны 5 (Приёмка ядра MVP)

**Нарядов в волне:** #29, #30, #31, #32  
**Протокол:** `docs/acceptance/wave-5.md` (по `docs/acceptance/TEMPLATE.md`)  
**Решает:** аудитор готовит протокол, владелец принимает решение go / go с замечаниями / no-go.

## Критерии
- [ ] 3 новых видео обработаны без правок кода и параметров
- [ ] Средняя оценка владельца ≥ 4 из 5
- [ ] Время и стоимость минуты зафиксированы в `docs/cost.md`
- [ ] Инструкция работает на чистой машине
- [ ] `docs/limitations.md` честно перечисляет слабости
- [ ] Решения по волне 6+ приняты (оболочка, второй пресет, тарифы, провайдеры)

## No-go
Низкая оценка или неприемлемая себестоимость: возврат к качеству и экономике до веб-оболочки.

## Порядок
1. Все наряды волны закрыты, PR прошли аудит.
2. Аудитор запускает проверки сам (не со слов агента) и заполняет протокол числами из запусков.
3. Демонстрация владельцу, решение записывается в протокол.
4. При go: аудитор уточняет черновики нарядов следующей волны (снимает `draft`).
