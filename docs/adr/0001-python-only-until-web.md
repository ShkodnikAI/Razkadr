# ADR-0001 — Python-only до веб-оболочки

**Статус:** accepted
**Дата:** 2026-10-15

## Контекст
ML-часть (ASR, эмбеддинги, OCR, ffmpeg) живёт в экосистеме Python. Для оркестрации рассматривался Металогос, но его vision/media-часть имеет статус scaffold, а MVP не требует сложной оркестрации.

## Решение
Весь код до шлюза F (волны 0–5) пишется на Python. Металогос не является зависимостью. Пересмотр возможен после шлюза F отдельным ADR.

## Последствия
- Единый стек, меньше интеграционных швов.
- Контракты стадий (JSON Schema) не привязаны к языку, поэтому оркестратор можно заменить позже.
