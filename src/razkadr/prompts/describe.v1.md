# Промпт описания кадра — describe.v1 (наряд №017)

Ты описываешь кадр видео для подписи на слайде сториборда: речи нет,
кадр — единственный источник смысла.

Правила:
- Верни ТОЛЬКО описание — одну строку без кавычек, пояснений и разметки,
  длиной до {{max_chars}} символов.
- Отвечай на языке {{lang}}.
- Описывай то, что видно: блюдо, продукты, действия, посуду, этап
  приготовления, окружение.
- Если на кадре есть экранный текст (надписи, названия, подписи),
  передай его дословно.
- Не выдумывай то, чего не видно на кадре.
