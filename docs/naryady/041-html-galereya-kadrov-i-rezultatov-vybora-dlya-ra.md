# Наряд №041 — HTML-галерея кадров и результатов выбора (для разметки и приёмки)

**Волна:** 1 (Индексатор)  
**Стадия:** eval  
**Размер:** M  
**Исполнитель:** agent  
**Зависит от:** #6  
**Связанные ADR:** —  
**Статус:** open

## Контекст
Эталонные кадры придётся размечать человеку, а результаты выбора проверять глазами на шлюзах. Для этого нужна простая статическая страница с кадрами и таймкодами.

## Контракт
```
`razkadr gallery runs/<id> [--storyboard storyboard.json] [--labels data/eval/labels/<id>.json]`
→ runs/<id>/gallery.html: сетка кадров с таймкодами; кликабельный таймкод; при наличии Storyboard кадры выбора подсвечены ролью; при наличии разметки отмечены эталонные кадры
```

## Scope
- Самодостаточная HTML-страница (миниатюры, ленивая загрузка, без внешних зависимостей и CDN).
- Режим «лист разметки»: кадры каждые N секунд с таймкодами, копирование таймкода по клику.
- Режим «просмотр выбора»: кадры из Storyboard по ролям, альтернативы, оценки.

## Non-goals
- Редактор Storyboard (веб-волны).

## Acceptance criteria
- [ ] Страница открывается локально без сервера и без сети
- [ ] Тест: количество кадров и таймкоды на странице соответствуют `frames.json`
- [ ] Режимы разметки и просмотра выбора работают на фикстуре
- [ ] CI зелёный

## Assumptions / Open questions
- Страница не предназначена для публикации и может содержать пути к локальным файлам.

## Проверка аудитора
- Открыть страницу в браузере и проверить удобство разметки на реальном ролике (этап шлюза B).
- Проверить отсутствие внешних запросов.
