# Наряд №024 — PDF из PPTX (LibreOffice headless)

**Волна:** 4 (Раскладка и экспорт)  
**Стадия:** render  
**Размер:** S  
**Исполнитель:** agent  
**Зависит от:** #22  
**Связанные ADR:** ADR-0003  
**Статус:** open

## Контекст
PDF — производный формат от мастера PPTX (ADR-0003).

## Контракт
```
`razkadr export-pdf deck.pptx [--out deck.pdf]`
→ deck.pdf; число страниц = числу слайдов; код 0
```

## Scope
- Вызов `soffice --headless --convert-to pdf` в изолированном профиле (временный `-env:UserInstallation`), таймаут из конфигурации.
- Понятные ошибки: нет LibreOffice (с подсказкой по установке), таймаут, пустой результат.
- Проверка шрифтов: предупреждение, если шрифт шаблона не найден в системе (подмена ухудшает вид).

## Non-goals
- Свой PDF-рендер.

## Acceptance criteria
- [ ] Пример из контракта проходит на deck.pptx из №22 (тест с меткой `libreoffice`)
- [ ] Число страниц PDF равно числу слайдов (проверка через pypdf или pdfinfo)
- [ ] Отсутствие `soffice` даёт код 1 и понятное сообщение (тест с подменой PATH)
- [ ] CI зелёный

## Assumptions / Open questions
- Параллельные запуски не гарантируются (общий профиль LibreOffice); изолированный профиль на запуск это снимает.

## Проверка аудитора
- Сравнить PDF с PPTX глазами на эталонном шаблоне.
