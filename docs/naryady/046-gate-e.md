# Шлюз E — приёмка волны 4 (Раскладка и экспорт)

**Нарядов в волне:** #21, #22, #23, #24, #25, #26, #27, #28  
**Протокол:** `docs/acceptance/wave-4.md` (по `docs/acceptance/TEMPLATE.md`)  
**Решает:** аудитор готовит протокол, владелец принимает решение go / go с замечаниями / no-go.

## Критерии
- [ ] `razkadr build` на 8/8 видео без ручных правок создаёт PPTX, PDF, HTML, JSON
- [ ] PPTX открывается в PowerPoint и LibreOffice без запроса на восстановление
- [ ] Google Slides: 3 файла, текст не обрезан; расхождения перечислены
- [ ] Собственный шаблон владельца заполняется корректно
- [ ] Кириллица и латиница верны во всех форматах
- [ ] Визуальные тесты зелёные
- [ ] Таймкоды в слайдах соответствуют кадрам (20 эпизодов, ≤ 2 с)

## No-go
Документ требует ручной доработки на большинстве видео: улучшаем макеты и автоподгон, а не добавляем форматы.

## Порядок
1. Все наряды волны закрыты, PR прошли аудит.
2. Аудитор запускает проверки сам (не со слов агента) и заполняет протокол числами из запусков.
3. Демонстрация владельцу, решение записывается в протокол.
4. При go: аудитор уточняет черновики нарядов следующей волны (снимает `draft`).
