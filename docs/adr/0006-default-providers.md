# ADR-0006 — Провайдеры по умолчанию (ASR, эмбеддинги, VLM, LLM)

**Статус:** proposed (принимает владелец после замеров на ключах)
**Дата:** 2026-10-16
**Наряд:** #004. Тарифы и условия: [docs/providers.md](../providers.md),
замерочный скрипт: `scripts/providers/measure.py`.

## Контекст
ADR-0004 фиксирует: модели только внешние (API), BYOK, вызовы после дешёвой
отбраковки и с кэшем. Наряд #004 требует выбрать набор по умолчанию и запасной
по проверенным условиям и замерам. Тарифы кандидатов собраны с официальных
страниц (дата проверки 2026-10-16, ссылки в docs/providers.md); замеры задержки
и качества выполняются скриптом при наличии ключей владельца. Для каждого
кандидата ниже указан расчёт по тарифу; окончательное утверждение — по числам
замеров и проверке условий (регион владельца, тексты политик).

## Решение (предлагается)

| Задача | По умолчанию | Запасной | Ключевой критерий выбора |
|---|---|---|---|
| ASR | Google `gemini-3.5-transcribe` | Deepgram `nova-3` (multilingual) | цена (~$0.003/мин по тарифу), автодетект языка, таймкоды через JSON-схему; запасной — независимый вендор с per-minute биллингом |
| Эмбеддинги | Путь «VLM-описание + текст»: `text-embedding-3-small` (1536d, $0.02/1M ток) | Мультимодальные: Cohere `embed-v4.0` / Jina `jina-embeddings-v4` (PAYG-тариф уточнить замером) | гарантированный публичный тариф и размерность; выбор подхода остаётся за ADR-0002 (данные шлюза C) |
| VLM (OCR, описания кадров) | Google `gemini-3.5-flash-lite` | OpenAI `gpt-6-luna` | единый тариф на все модальности ($0.30/1M ток); запасной — при подтверждении standard-тарифа |
| LLM (сжатие, перевод) | OpenAI `gpt-6-luna` | Google `gemini-3.5-flash-lite` / `gemini-3.7-flash` | самая низкая batch/flex-цена ($0.05/$0.25 на 1M ток); standard-тариф подтвердить замером |

Открытые условия утверждения (все помечены «требует уточнения» в docs/providers.md):
1. PAYG-тарифы: Cohere embed-v4.0, Jina v4, gemini-embedding-001, standard gpt-6-luna.
2. Регион владельца: доступность OpenAI/Google/Deepgram/ElevenLabs из его юрисдикции.
3. Условия данных: Gemini free-tier обучается на данных — только paid-tier; политики
   остальных перепроверить при выдаче ключей.
4. Замеры: задержка (min/median/max), WER на минуте речи, OCR-совпадение на 20 кадрах,
   списанные токены — `scripts/providers/measure.py`, результаты в docs/providers.md.

## Последствия
- Адаптеры (наряды 037–039) реализуются для «по умолчанию» и «запасной» из таблицы;
  смена провайдера — конфигурацией, без правок стадий (слой провайдеров, наряд 033).
- Тарифы и даты проверки фиксируются в `scripts/providers/tariffs.json`; при изменении
  цен обновляются тариф, дата и ссылка на источник.
- Если замеры опровергнут выбор (цена/задержка/качество), ADR обновляется до accept
  с фактическими числами; запасной кандидат остаётся резервом.
- Free-tier Gemini для данных владельца не используется (обучение на данных).
