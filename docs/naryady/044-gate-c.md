# Шлюз C — приёмка волны 2 (Отбор)

**Нарядов в волне:** #12, #13, #14, #15, #16  
**Протокол:** `docs/acceptance/wave-2.md` (по `docs/acceptance/TEMPLATE.md`)  
**Решает:** аудитор готовит протокол, владелец принимает решение go / go с замечаниями / no-go.

## Критерии
- [ ] hit@3 ≥ 80 % для ролей hero и steps на эталоне
- [ ] hit@3 ≥ 70 % для ingredients
- [ ] Сравнены текст-only / кадры-only / гибрид и минимум два подхода к эмбеддингам, со стоимостью минуты
- [ ] ADR-0002 принят с данными
- [ ] Storyboard-черновик валиден на 8/8 видео
- [ ] Владелец просмотрел выбор на 3 видео через галерею и признал кадры пригодными

## No-go
hit@3 < 80 % по hero и steps. Разбор причин и до двух итераций; затем пересмотр объёма проекта до волн 3–4.

## Порядок
1. Все наряды волны закрыты, PR прошли аудит.
2. Аудитор запускает проверки сам (не со слов агента) и заполняет протокол числами из запусков.
3. Демонстрация владельцу, решение записывается в протокол.
4. При go: аудитор уточняет черновики нарядов следующей волны (снимает `draft`).
