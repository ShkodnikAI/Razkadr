# Наряд №007 — Транскрипт через ASR-провайдера

**Волна:** 1 (Индексатор)  
**Стадия:** indexer  
**Размер:** M  
**Исполнитель:** agent  
**Зависит от:** #33, #35, #5  
**Связанные ADR:** ADR-0004  
**Статус:** open

## Контекст
Речь в видео превращается в текст с таймкодами через внешний ASR (слой провайдеров). Длинные файлы режутся на части.

## Контракт
```
runs/<id>/audio.wav
→ transcript.json: язык (авто), сегменты {t_start, t_end, text}, при наличии слова с таймкодами
```

## Scope
- Нарезка длинного аудио на части с перекрытием (параметры: длина части, перекрытие) и склейка результата с корректным смещением времени и удалением дублей на стыках.
- Автоопределение языка (результат провайдера) и возможность задать язык принудительно.
- Видео без речи: валидный пустой транскрипт, не ошибка.
- Учёт стоимости (секунды аудио) через слой провайдеров; кэш по хэшу аудио.

## Non-goals
- Реальный адаптер провайдера (№37).
- Диаризация спикеров (поздние волны).
- Разбивка на чанки (№8).

## Acceptance criteria
- [ ] Тест на fake-ASR: склейка частей даёт монотонные таймкоды без дублей на стыках
- [ ] Пустой транскрипт для аудио без речи
- [ ] `transcript.json` валиден по схеме из №35
- [ ] Стоимость и cache_hit записаны в `run.json`
- [ ] CI зелёный

## Assumptions / Open questions
- Формат ответа конкретного провайдера приводится к единому типу в адаптере, не в стадии.

## Проверка аудитора
- Проверить граничные случаи: аудио короче одной части, аудио ровно на границе части, перекрытие больше длины.
- Проверить, что стадия не знает ничего о конкретном провайдере.
