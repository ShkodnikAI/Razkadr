# Наряд №033 — Слой провайдеров и BYOK

**Статус:** open
**Волна:** 1
**Стадия конвейера:** инфраструктура
**Версия схемы Storyboard:** 1.0
**Связанные ADR:** 0004
**Зависит от:** №001, №004

## Контракт
```
config.toml:
  [asr]        provider = "<имя>"  model = "<модель>"  api_key_env = "ASR_API_KEY"
  [embeddings] provider = "<имя>"  ...
  [vlm] / [llm] аналогично
→
transcribe(audio_path) -> Transcript          # единый тип результата для любого провайдера
embed_images(paths) / embed_texts(texts) -> list[Vector]
describe_image(path, prompt) -> str
complete(messages) -> str
→ каждый вызов дописывает в run.json: стадия, провайдер, модель, секунды или токены, стоимость, cache_hit
→ смена `provider` в конфиге не требует правки кода стадий
```

## Scope
- Интерфейсы (Protocol) для ASR, эмбеддингов, VLM, LLM и единые типы результатов.
- 2 реализации на каждую задачу, где это возможно (по итогам наряда 004), плюс заглушка (fake) для тестов без сети.
- Ключи: из переменных окружения или конфига; режим BYOK = ключи пользователя; режим платформы = ключи платформы (выбор источника ключа на стороне вызова).
- Кэш вызовов по хэшу входа и параметров (платный вызов не повторяется).
- Учёт стоимости по тарифам из конфига (тарифы задаются вручную и датируются).
- Повторы с ожиданием при временных ошибках, понятные ошибки при неверном ключе или исчерпанной квоте.
- Маскирование ключей в логах и `run.json`.

## Non-goals
- Хранение ключей пользователей в БД и шифрование в хранилище (веб-волны).
- Биллинг пользователей.
- Реализация стадий (они используют слой).

## Acceptance criteria
- [ ] Пример из контракта проходит на fake-провайдере без сети (тест)
- [ ] Для каждой реализованной задачи проверен реальный провайдер (ручной запуск, результат записан)
- [ ] Смена провайдера правкой конфига подтверждена тестом
- [ ] Повторный вызов с теми же входами не обращается к API (тест на счётчик вызовов)
- [ ] Ключи отсутствуют в логах, `run.json` и исключениях (тест)
- [ ] CI зелёный, документация конфига добавлена
- [ ] PR содержит `Closes #033`

## Assumptions / Open questions
- Набор провайдеров определяется нарядом 004.
- Пакетные вызовы и лимиты частоты настраиваются в конфиге провайдера.
