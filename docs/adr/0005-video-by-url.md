# ADR-0005 — Видео по ссылкам (YouTube, TikTok и др.)

**Статус:** accepted для CLI-ядра и внутренней оценки; для хостед-сервиса deferred
**Дата:** 2026-10-15

## Контекст
Владелец хочет принимать видео по ссылкам платформ. Скачивание загрузчиками (yt-dlp) может противоречить условиям платформ и затрагивать права авторов; платформы блокируют загрузчики, ссылки ломаются, TikTok и подобные сервисы меняют доступ часто.

## Решение
- В CLI-ядре (волны 0–5) приём ссылок через yt-dlp входит в наряд 005. Он используется владельцем для собственных и тестовых видео, источник каждого видео фиксируется.
- Эталонный набор хранится локально вне git; копии не распространяются.
- Для публичного хостед-сервиса приём чужих ссылок требует отдельного решения (юридическая оценка, ограничение «только свои видео и видео с правом использования», согласие пользователя); до этого решения не включается.

## Последствия
- Ссылки могут перестать работать: источники фиксируются в `SOURCES.md`, локальная копия обязательна.
- Загрузчик может требовать обновления и обработки ошибок (наряд 005).
- Это решение не является юридической консультацией.
