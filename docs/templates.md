# Пользовательский шаблон PPTX (наряд №023)

`razkadr render --template my.pptx` кладёт слайды в ваш дизайн. Код вы не
правите — вы следуете соглашению об именах, а `razkadr template-check`
говорит, чего в шаблоне не хватает до рендера.

```bash
razkadr template-check my.pptx      # отчёт по макетам и слотам; 0 = готов
razkadr render slides.json --template my.pptx --out deck.pptx
```

`template-check` понимает и эталонный шаблон (макеты `title`, …,
плейсхолдеры `heading`, …), и пользовательский диалект ниже; код 0 —
рендер возможен, код 1 — перечень недостающего, код 2 — файл не PPTX.

## Соглашение об именах

**Макеты** — пять, имена фиксированы (это макеты раскладки №021):

| Имя layout | Откуда |
|---|---|
| `razkadr:title` | титульный слайд (один на деку) |
| `razkadr:hero_caption` | каждый hero-эпизод |
| `razkadr:ingredients_list` | группа эпизодов роли ingredients |
| `razkadr:steps_grid` | группа эпизодов роли prep/step |
| `razkadr:serving` | каждый serving-эпизод |

**Плейсхолдеры слотов** — обычные фигуры-плейсхолдеры PowerPoint, названные
по схеме `slot:<что>`:

| Имя | Содержимое | Где обязателен |
|---|---|---|
| `slot:title` | заголовок (проект или «Ингредиенты»/«Шаги»/«Подача») | title, ingredients_list, steps_grid, serving |
| `slot:subtitle` | подзаголовок титула | title (опционально) |
| `slot:image_1` | кадр | во всех макетах |
| `slot:caption` | текст эпизода | hero_caption, serving |
| `slot:timecode` | таймкод `мм:сс` | hero_caption, serving (опционально) |
| `slot:list` | строки ингредиентов (маркеры `«• »` добавит рендер) | ingredients_list |

**steps_grid** — сетка шагов; до шести групп ячеек, каждая группа — четыре
плейсхолдера с одним номером `N` от 1 до 6:

| Имя | Содержимое | Обязательность |
|---|---|---|
| `slot:image_N` | кадр шага | N=1 обязателен (с `slot:text_1`), N=2..6 опциональны |
| `slot:text_N` | текст шага | N=1 обязателен, N=2..6 опциональны |
| `slot:number_N` | номер шага | опционально |
| `slot:timecode_N` | таймкод шага | опционально |

Необязательный плейсхолдер может отсутствовать — слот молча пропускается.
Отсутствие обязательного — `template-check` код 1, рендер предупредит.
Позиции и размеры вы задаёте как угодно: рендер вписывает кадры в боксы
вашего `slot:image_N` с сохранением пропорций (contain-fit, по центру),
текст автоподгоняется под размер шрифта вашего плейсхолдера (пол
`--min-font-pt`, ниже — предупреждение). Если шагов в деке больше, чем
групп ячеек, лишние шаги отбрасываются с предупреждением `cells_overflow`.

## Схемы слотов (текстовые)

```
razkadr:title                       razkadr:hero_caption
+-------------------+               +------------+----------------+
| [slot:title]      |               | slot:image_1  | slot:caption |
| [slot:subtitle]   |               | (кадр)        | (текст)      |
| [slot:image_1]    |               |               | slot:timecode|
+-------------------+               +------------+----------------+

razkadr:ingredients_list            razkadr:steps_grid (группы N=1..6)
+---------------------------------+  +--------------------------------+
| [slot:title]                    |  | [slot:title]                   |
| [slot:list]      | [slot:image_1]|  | [slot:number_1]  [slot:image_1] |
| (строки списка)  | (кадр)       |  | [slot:text_1]                    |
+---------------------------------+  | ... группа 2, ..., группа 6      |
                                     +--------------------------------+

razkadr:serving
+---------------------------------+
| [slot:title]                    |
| [slot:image_1]   [slot:caption] |
|                  [slot:timecode]|
+---------------------------------+
```

## Пошагово в PowerPoint

1. Откройте свой .pptx → вкладка «Вид» → «Образец слайдов».
2. В мастере создайте пять макетов (кнопка «Вставить макет»), для каждого
   в панели «Переименовать» задайте имя `razkadr:title`, `razkadr:hero_caption`,
   `razkadr:ingredients_list`, `razkadr:steps_grid`, `razkadr:serving` —
   префикс `razkadr:` обязателен.
3. На каждом макете расставьте плейсхолдеры («Вставить заполнитель» →
   текст/картинка), затем в области выделения (Alt+F10) переименуйте их
   по таблице выше: `slot:title`, `slot:image_1`, … Имя — единственный
   признак слота; тип (текст/картинка) подсказывает PowerPoint что вставлять.
4. Оформите фон, логотип, цвета и шрифты макетов — всё статическое
   останется как есть, рендер заполняет только слоты.
5. Сохраните файл и проверьте: `razkadr template-check my.pptx` — добейтесь
   кода 0, отчёт покажет недостающие слоты поимённо.
6. Рендер: `razkadr render slides.json --template my.pptx --out deck.pptx`,
   затем PDF: `razkadr export-pdf deck.pptx`.

Подсказки: шаги (steps_grid) не обязаны иметь все шесть групп — рендер
использует столько, сколько есть, в порядке номеров; таймкоды — необязательные
слоты; для проверки «как это выглядит» прогоните рендер на
`examples/artifacts/slides.json`. Реальный шаблон владельца проверяется на
шлюзе E.
