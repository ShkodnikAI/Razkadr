# Наряд №005 — Ingest: файл или ссылка, нормализация, метаданные

**Волна:** 1 (Индексатор)  
**Стадия:** ingest  
**Размер:** M  
**Исполнитель:** agent  
**Зависит от:** #35, #36  
**Связанные ADR:** ADR-0005  
**Статус:** open

## Контекст
Первая стадия конвейера. Принимает локальный файл или ссылку (YouTube, TikTok и др. через yt-dlp), приводит видео к единому формату и извлекает звук.

## Контракт
```
`razkadr index <файл|URL>`  (стадия ingest)
→ runs/<id>/normalized.mp4, audio.wav (16 кГц, моно), source.json (источник, sha256, длительность, fps, разрешение, дорожки, версии ffmpeg и yt-dlp)
```

## Scope
- Приём локального файла и URL (yt-dlp); определение отсутствия звуковой дорожки (флаг в `source.json`, не ошибка).
- Нормализация ffmpeg: контейнер mp4, ограничение разрешения и fps параметрами конфигурации.
- Понятные ошибки: недоступная ссылка, видео удалено/приватное, нет ffmpeg, файл повреждён, превышен лимит длительности/размера (параметр).
- Тесты на фикстурах из №34; yt-dlp в тестах подменяется (сети в CI нет).

## Non-goals
- Политика приёма чужих ссылок в хостед-сервисе (ADR-0005, deferred).
- Загрузка через браузер (веб-волны).

## Acceptance criteria
- [ ] Пример из контракта проходит на фикстуре (файл)
- [ ] Ветка URL протестирована на подмене yt-dlp (успех, недоступно, нет сети)
- [ ] `source.json` валиден по схеме из №35
- [ ] Видео без звука обрабатывается без падения
- [ ] Ручная проверка владельцем: по одной ссылке YouTube и TikTok (результат записан в PR)
- [ ] CI зелёный

## Assumptions / Open questions
- yt-dlp ставится как зависимость; его обновление и блокировки платформ — известный риск (ADR-0005).

## Проверка аудитора
- Проверить, что скачанные видео не попадают в git.
- Проверить обработку нестандартных входов: файл с пробелами в имени, очень короткое видео, VFR.
