# Наряд №004 — Замеры окружения и ADR по лицензиям моделей

**Статус:** open (блокируется: нужна информация о железе)
**Волна:** 0
**Стадия конвейера:** инфраструктура / решения
**Связанные ADR:** 0002, создаёт 0004
**Зависит от:** №001

## Контракт
```
железо проекта + 1 минута тестового видео
→ docs/env.md: CPU/GPU/RAM, время ASR (faster-whisper) и эмбеддингов кадров (SigLIP 2) на 1 минуту, пиковая память
→ docs/adr/0004-model-licenses.md: таблица «модель → лицензия → допустима ли для коммерческого сервиса → вывод»
```

## Scope
- Замеры ASR и эмбеддингов на доступном железе.
- Проверка лицензий по первоисточникам (страницы моделей и лицензионные файлы): SigLIP 2, jina-clip-v2, faster-whisper/Whisper, OCR-движок, VLM-кандидаты, LLM-кандидаты.
- Рекомендация по умолчанию для MVP.

## Non-goals
- Выбор финальной модели эмбеддингов (ADR-0002, после волны 2).
- Юридическая консультация: вывод помечается как требующий проверки юристом при коммерческом запуске.

## Acceptance criteria
- [ ] `docs/env.md` содержит замеры, полученные запуском (команды приведены)
- [ ] ADR-0004 со ссылками на источники лицензий
- [ ] Для каждой модели указан статус: разрешена / ограничена / требует уточнения
- [ ] PR содержит `Closes #004`

## Assumptions / Open questions
- Какое железо доступно (GPU или только CPU) — вопрос к владельцу.
