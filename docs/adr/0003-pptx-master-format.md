# ADR-0003 — PPTX как мастер-формат презентаций

**Статус:** accepted
**Дата:** 2026-10-15

## Контекст
Нужны три формата сразу: PPTX, PDF, Google Slides. Строить каждый отдельным рендерером дорого и увеличивает расхождения.

## Решение
Единственный рендерер презентаций строит PPTX (python-pptx, с поддержкой пользовательского шаблона). PDF получается конвертацией PPTX (LibreOffice headless), Google Slides загрузкой PPTX в Drive с конвертацией. HTML и JSON строятся напрямую из Storyboard.

## Последствия
- Один источник истины для оформления.
- Расхождения при конвертации (шрифты, автоподгон) ловятся визуальными тестами и перечисляются в `limitations.md`.
- Google Slides требует OAuth пользователя (наряд 025).
