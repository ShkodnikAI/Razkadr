**Статус:** open

## Контекст
PPTX — мастер-формат (ADR-0003). Рендер заполняет слайды шаблона данными из slides.json; PDF и Google Slides получаются из этого файла.

## Контракт
```
`razkadr render slides.json --out deck.pptx [--template templates/razkadr-default.pptx]`
→ deck.pptx: по слайду на каждый слайд slides.json; кадры вписаны без искажения пропорций; текст, таймкоды на месте; кириллица и латиница читаемы
```
Эталонный шаблон `templates/razkadr-default.pptx` создаётся скриптом `scripts/templates/build_default.py` (палитра и шрифт проекта: бордовый #6B0F1A, шампань #D4AF7F, кремовый #F8F4E9, графит #2B2B2B; шрифт с кириллицей, доступный в LibreOffice по умолчанию в CI). У шаблона по одному layout на макет из №21 (`title`, `hero_caption`, `ingredients_list`, `steps_grid`, `serving`) с именованными плейсхолдерами под слоты.

## Scope
- Скрипт сборки эталонного шаблона и сам `.pptx` в репозитории (небольшой); воспроизводимость сборки проверяется тестом.
- Рендер: заполнение плейсхолдеров, вставка кадров (вписывание с сохранением пропорций), таймкоды, автоподбор размера шрифта в пределах слота (нижняя граница задаётся; ниже — предупреждение).
- Заметки докладчика: в `notes` каждого слайда id эпизода, таймкод начала и конца, источник — чтобы по слайду можно найти момент видео.
- Подкоманда `razkadr render` и документация `docs/render.md`.

## Non-goals
- PDF (№24), Google Slides (№25), HTML/JSON (№26).
- Пользовательские шаблоны (№23).
- Анимации и переходы.

## Acceptance criteria
- [ ] Пример из контракта проходит на `slides.json` из №21 (по примеру Storyboard)
- [ ] Тест: файл открывается python-pptx; число слайдов, картинок и текстовых слотов соответствует slides.json
- [ ] Тест: ни один текст не выходит за границы слота (оценка по размерам, метод описан в PR)
- [ ] Проверка конвертации в LibreOffice (`soffice --headless --convert-to pdf`) проходит без ошибок (тест с меткой `libreoffice`, пропускается без `soffice`)
- [ ] Кириллица и латиница: тестовый Storyboard с обоими алфавитами; шрифт в PDF-проверке не подменяется на «квадратики» (проверка текста PDF через pdftotext или аналог)
- [ ] Сборка шаблона воспроизводима
- [ ] CI зелёный
