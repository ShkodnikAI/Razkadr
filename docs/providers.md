## 6. Команды замеров

Скрипты: `scripts/providers/measure.py` (+ [README](../scripts/providers/README.md) с полной
матрицей). Ключи — только в переменных окружения (`OPENAI_API_KEY`, `GEMINI_API_KEY`,
`DEEPGRAM_API_KEY`, `ELEVENLABS_API_KEY`, `COHERE_API_KEY`, `JINA_API_KEY`); проверка
готовности без сети:

```bash
.venv/bin/python scripts/providers/measure.py --dry-run
```

Пример запуска ASR (полный список — в README скрипта):

```bash
.venv/bin/python scripts/providers/measure.py --task asr \
  --provider gemini-transcribe --provider deepgram-nova3 \
  --audio /path/to/one-minute-speech.mp4 --repeat 3 \
  --out runs/providers/asr.json
```

Результаты (`results.json`) содержат по каждому провайдеру: min/median/max задержки,
списанное usage, стоимость по тарифу `tariffs.json` и (при наличии эталона) WER/совпадение
OCR. Таблицы в разделах 1–4 заполняются этими числами после запуска; числа только из
реальных запусков.
