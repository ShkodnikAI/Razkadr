# Бренд Razkadr

Название пишется латиницей: **Razkadr** (в коде и пакете `razkadr`, в логотипе заглавными: RAZKADR).
Слоган (рабочий): «Video in, deck out».

## Идея знака
Диафрагма (камера) в кольце киноленты: перфорация по краям, 20 кадров, в центре треугольник play. Знак говорит: «видео → кадры → результат».

## Цвета
| Роль | Цвет | HEX |
|---|---|---|
| Бордовый (основной) | burgundy | `#6B0F1A` |
| Тёмный бордовый | deep burgundy | `#4A0B14` |
| Шампань (акцент) | champagne gold | `#D4AF7F` |
| Крем (фон, светлый) | cream | `#F8F4E9` |
| Угольный (текст, тёмный фон) | dark slate | `#2B2B2B` |

## Шрифт надписи
Cinzel SemiBold, заглавные, трекинг +6 %. В файлах логотипа надпись уже переведена в контуры, шрифт для использования логотипа не нужен. Шрифт распространяется по лицензии SIL OFL (Google Fonts / Fontsource); перед коммерческим использованием проверьте лицензию.
Для текста интерфейса и документов рекомендуется спокойный гротеск (например, Montserrat или Inter), а не Cinzel.

## Файлы
| Файл | Где использовать |
|---|---|
| `logo-horizontal.svg` (+ `-on-dark`, `-mono`) | основной логотип: шапка сайта, документы, слайды |
| `logo-vertical.svg` (+ `-on-dark`, `-mono`) | титульные слайды, обложки, квадратные поля |
| `logo-mark.svg` (+ `-on-dark`, `-mono`) | знак без надписи, от 48 px |
| `mark-simple.svg` (+ `-on-dark`, `-mono`) | упрощённый знак без ленты: меньше 48 px, аватары, мелкие места |
| `icon.svg`, `icon-512.png` | иконка приложения, favicon |
| `logo-horizontal.png`, `logo-mark.png` | растровые копии (README, превью) |

## Правила
- Полный знак с лентой не использовать меньше 48 px; ниже брать `mark-simple` или `icon`.
- На тёмных фонах только версии `-on-dark`; на однотонной печати и штампах версии `-mono`.
- Свободное поле вокруг знака не меньше половины ширины одного кадра ленты.
- Не растягивать, не перекрашивать вне палитры, не добавлять тени и градиенты, не менять надпись.

## Известные оговорки
- Диафрагма и киноплёнка — распространённые образы; сходство с существующими логотипами не проверялось и юридически не оценивалось. Проверить перед публичным запуском.
- Окружности в SVG записаны многоугольниками (так получены настоящие вырезы). Для печатного макета знак стоит перерисовать в векторном редакторе.

## Сборка
Скрипты в `scripts/brand/` (нужны `shapely` и `fonttools`):
```bash
mkdir -p /tmp/brand_work && cd /tmp/brand_work
python <repo>/scripts/brand/build_aperture.py          # простой знак и иконка
python <repo>/scripts/brand/build_aperture_strip.py    # знак с лентой
python <repo>/scripts/brand/build_final.py <путь к Cinzel 600 .woff> <repo>/docs/brand
```
