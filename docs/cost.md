# Себестоимость минуты видео (наряд №030)

**Статус: методика + структура цены на условных тарифах.** Реальные тарифы провайдеров собирает наряд №004 (заблокирован отсутствием ключей у владельца); до него все цены в этом документе — явно заданные условные значения, служащие для проверки учётной механики (наряд №033) и относительной структуры цены. Формулы и выводы о структуре («что доминирует в цене») устойчивы к замене тарифов; абсолютные цифры — нет.

## Методика

Серия реальных прогонов `razkadr build` (наряд №028) на синтетической фикстуре №034: видео 320×240, 10 fps, **30 с**, 5 сцен, аудиодорожка (синус 440 Гц). Провайдеры — детерминированные fake-реализации №033, каждый вызов записывается в `run.json` (провайдер, модель, единицы, цена, кэш-хит). Таблицы ниже — арифметика над записанными `run.json` без какой-либо дополнительной тарификации: агрегатор `scripts/cost_report.py` (тесты — `tests/test_cost_report.py`).

Условные тарифы серии (единый день `2026-10-01`, валюта USD):

| задача | единица тарификации | цена за единицу |
|---|---|---:|
| asr (fake-nova-2) | секунда аудио | 0.0059 |
| vlm (fake-vision-1) | изображение | 0.0013 |
| llm (fake-gpt-4o-mini) | токен | 0.0000006 |
| embeddings (fake-embed-v2) | изображение (кадры) | 0.00002 |

Воспроизведение: сгенерировать фикстуру (`python tests/fixtures/make_fixtures.py <dir>`, склеить аудио ffmpeg'ом), положить конфиг с fake-провайдерами и таблицей тарифов выше, выполнить `razkadr build <video> --preset recipe` трижды (холодный; `--resume <run_id>`; холодный со свежим каталогом кэша вызовов), затем:

```bash
python scripts/cost_report.py runs/<id-1> runs/<id-3> \
  --label "холодный (свежий кэш вызовов)" \
  --label "повторный холодный (свежий кэш)"
```

## Наблюдения

1. **Цена почти целиком в ASR**: 0.059 из 0.068355 (86.3%) — транскрипт. OCR — 12.6% на этом материале (4 из 4 кадров отправлены — доли OCR/ASR зависят от насыщенности экранного текста и длины речи), генерация текста — 5.8%, эмбеддинги — 0.1%. Вывод для экономики: оптимизировать сначала ASR (тариф провайдера, длина аудио), потом OCR-отбор.
2. **Детерминизм цены**: два независимых холодных прогона дали байт-в-байт одинаковые суммы (0.068355) и идентичное распределение по стадиям — стоимость воспроизводима, отчёт сравним между версиями пайплайна.
3. **Кэш — вторая ручка экономики**: кэш вызовов обнулил перегенерацию текста (+22 вызова, 0.000000 USD); в реальном режиме «правка → перегенерация → экспорт» платёж провайдеру происходит один раз на уникальный вход.
4. Суммы по стадиям и по провайдерам сходятся в итог (0.068355) — двойной контроль агрегации.

## Платформенные ключи против BYOK

Разделение режимов зафиксировано в spec §9.1 и ADR-0004: **BYOK** — пользователь подключает свои API-ключи и платит провайдеру напрямую; платформе остаются только её собственные сервисы. **Платформенные ключи** — платформа платит провайдеру из своего кармана и несёт полную API-стоимость.

- **BYOK-режим.** Платформенная себестоимость минуты = только собственные сервисы (оркестрация, рендер, хранение). В CLI-ядре оркестрация и рендер выполняются локально на машине пользователя, поэтому в измеренной серии платформенная составляющая — **0 USD/мин**; API-стоимость 0.1367 USD/мин проходит транзитом к провайдеру и пользователю не тарифицируется платформой. Кредитная модель (1 кредит ≈ 1 минута исходного видео, spec §10) при BYOK списывается только за собственные сервисы.
- **Платформенные ключи.** Полная API-стоимость ложится на платформу: на условных тарифах — **0.1367 USD/мин**, из них 86% ASR. К этой цифре добавляются собственные сервисы (хранение, трафик, рендер-парк). Свободный тир и цены подписок фиксируются только после реальных замеров №004.
- Учёт одинаков в обоих режимах: `run.json` фиксирует провайдера, модель, единицы, цену и кэш-хиты независимо от того, чей ключ использовался; режим ключей (`[keys] mode`) на структуру записи не влияет.

## Ограничения

- Фикстура 30 с, 4 принятых кадра, 10 с речи — пропорции стадий на реальном рецепте (более длинная речь, больше кадров) сместятся; абсолютные «за минуту» — на условных тарифах.
- Тариф эмбеддингов покрывает только изображения (кадры); текстовые эмбеддинги отбора (18 вызовов select, 36 токенов) в этой конфигурации бесплатны — до реальных адаптеров №038, где единица тарификации будет выбрана по факту биллинга провайдера.
- Реальная себестоимость минуты (шлюз B) считается на эталонном наборе №040 — восемь размеченных видео; эта страница будет переписана на реальных числах, когда ключи появятся (№004).
