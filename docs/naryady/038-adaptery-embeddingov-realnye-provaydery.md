# Наряд №038 — Адаптеры эмбеддингов (реальные провайдеры)

**Волна:** 1 (Индексатор)  
**Стадия:** infra  
**Размер:** M  
**Исполнитель:** agent  
**Зависит от:** #4, #33  
**Связанные ADR:** ADR-0006, ADR-0002  
**Статус:** open

## Контекст
Реальные адаптеры эмбеддингов по ADR-0006: мультимодальный провайдер (кадры и текст в одном пространстве) и/или текстовый провайдер для варианта «VLM-описание + текст».

## Контракт
```
[embeddings] provider = "<из ADR-0006>"  + ключ в окружении
→ embed_images(paths) и embed_texts(texts) возвращают векторы одной размерности, записанной в манифесте индекса
```

## Scope
- 1–2 адаптера, пакетные вызовы с учётом лимитов провайдера, ограничение размера изображений перед отправкой (параметры).
- Юнит-тесты на записанных ответах, live-тест с меткой.
- Документация конфигурации и тарифов.

## Non-goals
- Выбор подхода к эмбеддингам (ADR-0002 после волны 2).
- Реализация поиска (№12).

## Acceptance criteria
- [ ] Юнит-тесты проходят в CI без сети
- [ ] Live-тест проходит локально (результат приложен к PR)
- [ ] Размерность и модель попадают в манифест индекса
- [ ] Уменьшение изображений проверено тестом (отправляемый размер не превышает лимита)
- [ ] CI зелёный

## Assumptions / Open questions
- Если провайдер не даёт изображений, адаптер реализует только текст, а режим «VLM-описание + текст» опирается на №39.

## Проверка аудитора
- Проверить, что изображения не отправляются в избыточном разрешении (стоимость).
- Проверить, что размерность не зашита константой.
