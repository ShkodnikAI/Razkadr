## Контекст
Пресет — сценарий предметной области: какие роли кадров нужны, какими запросами они ищутся и как скорятся. Первый пресет — рецепты.

## Контракт
```
presets/recipe.yaml → загружается и валидируется по schemas/preset.v1.json
роли: hero (1), ingredients (1), prep (0..N), steps (3..12), serving (0..1)
для каждой роли: запросы (RU/EN), вес сигналов поиска, ограничения (мин. резкость, штраф за лица/руки в кадре ...), число кандидатов и альтернатив
```

## Scope
- `schemas/preset.v1.json` и загрузчик с понятными ошибками.
- `presets/recipe.yaml`: роли, запросы на русском и английском, ограничения числа эпизодов, правила порядка (hero → ingredients → steps → serving), минимальный интервал между шагами.
- Документация формата пресета в `docs/presets.md` (чтобы потом можно было добавлять пресеты без правки кода).

## Non-goals
- Алгоритм выбора (№14).
- Другие пресеты.

## Acceptance criteria
- [ ] Пресет валиден по схеме; тесты на невалидные пресеты (нет роли, отрицательный вес, пустые запросы)
- [ ] Добавление новой роли требует только правки YAML (тест на синтетическом пресете)
- [ ] `docs/presets.md` написан
- [ ] CI зелёный

## Assumptions / Open questions
- Запросы пресета — стартовые, уточняются по метрикам шлюза C.

## Проверка аудитора
- Проверить, что в коде нет захардкоженных ролей рецепта (всё из YAML).
