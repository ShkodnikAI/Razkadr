# SOURCES — происхождение эталонных видео

Одна строка таблицы — одно видео эталонного набора. Заполняется владельцем
при добавлении видео (наряд №40); `id` должен совпадать с именем файла
`videos/<id>.mp4` и разметки `labels/<id>.json`.

Поля: `id` — идентификатор видео; `ссылка` — источник (URL или описание);
`дата скачивания` — YYYY-MM-DD; `условия использования` — лицензия/право на
обработку; `локальный файл` — путь внутри `data/eval/` (обычно
`videos/<id>.mp4`); `теги` — через запятую, словарь тегов см. README.

Проверка целостности набора: `razkadr eval-check data/eval`.
