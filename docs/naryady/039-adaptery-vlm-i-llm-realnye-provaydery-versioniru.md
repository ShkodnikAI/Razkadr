# Наряд №039 — Адаптеры VLM и LLM (реальные провайдеры), версионируемые промпты

**Волна:** 1 (Индексатор)  
**Стадия:** infra  
**Размер:** M  
**Исполнитель:** agent  
**Зависит от:** #4, #33  
**Связанные ADR:** ADR-0006  
**Статус:** open

## Контекст
Реальные адаптеры для описаний кадров и OCR (VLM) и для текстовых задач (LLM: чанки, сжатие, перевод). Промпты хранятся в репозитории с версиями.

## Контракт
```
[vlm] / [llm] provider = "<из ADR-0006>"  + ключи в окружении
→ describe_image(path, prompt) -> str,  complete(messages) -> str
→ промпты: prompts/<имя>.v<N>.md, идентификатор версии пишется в run.json
```

## Scope
- 1–2 адаптера для VLM и LLM; режим структурированного (JSON) ответа с проверкой и повтором при невалидном ответе.
- Каталог `prompts/` с версиями; загрузчик промптов; версия промпта в `run.json`.
- Юнит-тесты на записанных ответах, live-тесты с меткой.

## Non-goals
- Содержательные промпты волны 3 (текст рецептов, перевод): добавляются нарядами №17–18.
