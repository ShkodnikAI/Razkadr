# Наряд №037 — Адаптеры ASR (реальные провайдеры)

**Волна:** 1 (Индексатор)  
**Стадия:** infra  
**Размер:** M  
**Исполнитель:** agent  
**Зависит от:** #4, #33  
**Связанные ADR:** ADR-0006  
**Статус:** open

## Контекст
Реализация реальных адаптеров ASR для провайдеров, выбранных в ADR-0006 (наряд №4). Без ключа адаптеры не работают, но не должны ломать тесты.

## Контракт
```
[asr] provider = "<из ADR-0006>"  + ключ в окружении
→ `transcribe(audio.wav)` возвращает единый тип Transcript с реальными таймкодами
```

## Scope
- 1–2 адаптера (основной и запасной) по ADR-0006; приведение ответа к единому типу, нормализация таймкодов и языков.
- Юнит-тесты на записанных (обезличенных) ответах провайдера; интеграционный тест с меткой `live`, пропускаемый без ключа.
- Тарифы и единицы учёта в конфигурации, документация переменных окружения.
- Отображение ошибок провайдера (неверный ключ, лимит, недоступность) в понятные исключения слоя.

## Non-goals
- Выбор провайдеров (№4).
- Изменение интерфейса слоя провайдеров без согласования (если нужно, отдельный наряд).

## Acceptance criteria
- [ ] Юнит-тесты на записанных ответах проходят в CI без сети и ключей
- [ ] Live-тест проходит локально с ключом (результат приложен к PR, без ключа в тексте)
- [ ] Стоимость в `run.json` соответствует тарифу провайдера на 1 минуту (сверка с `docs/providers.md`)
- [ ] CI зелёный

## Assumptions / Open questions
- Записанные ответы не содержат персональных данных и ключей.

## Проверка аудитора
- Проверить, что в репозиторий не попали ключи и необезличенные ответы.
- Проверить сопоставление ошибок провайдера с исключениями слоя.
